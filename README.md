# ResumeRoute

A free, privacy-first ATS resume checker and resume builder tailored for India.

## Features

- In-browser resume checks and job-description matching
- Quantified-impact detection for achievement statements
- Live ATS-friendly one-column resume builder
- Multiple experiences, education entries, skills, projects, achievements, and custom sections
- DOCX and text resume import
- Browser print / Save as PDF
- No account or server-side resume storage
